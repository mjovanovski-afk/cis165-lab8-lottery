CIS 165 - Lab 8: Lottery Simulation

Inputs / Starting Data:
- Five random integers (0 through 9) generated by the program for winningDigits.
- Five integers (0 through 9) entered by the user for player.

Variables and Constants:
- Named constants: SIZE = 5, MIN_DIGIT = 0, MAX_DIGIT = 9, and SEED = 42.
- Integer arrays: winningDigits[SIZE] and player[SIZE].
- Counter variable: matchCount initialized to 0.

Calculations and Comparisons:
- Call srand(SEED) once before the generation loop using cstdlib.
- Use a for loop to assign (rand() % (MAX_DIGIT - MIN_DIGIT + 1)) + MIN_DIGIT to each index of winningDigits.
- Use a second for loop to read user input into each index of player.
- Use a third for loop to check if winningDigits[i] == player[i], incrementing matchCount when true.

Checks and Expected Output:
- Print all five elements of winningDigits, all five elements of player, and the final matchCount with clear labels.

COMPILE AND RUN INSTRUCTIONS

Using OnlineGDB:
1. Open OnlineGDB and paste the contents of lottery.cpp into the main editor.
2. Select C++17 from the Language dropdown menu in the top-right corner.
3. Click the green Run button at the top of the screen to compile and execute the program.
4. Enter five digits (0 through 9) in the bottom console window when prompted.
